## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Riteshpatil077/devCodes.git
cd devCodes
```

### 2. Running Individual Projects
Each project subdirectory is modular. To run any specific React or Next.js application:

```bash
# Navigate to desired project directory, for example:
cd react/password-generator
# or
cd nextjs-project/project/Admin-Dashboard

# Install dependencies
npm install

# Start development server
npm run dev
```
